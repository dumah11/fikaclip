Privacy Policy

FikaClip Content Poster

Last updated 1 October 2026

FikaClip Content Poster ("the Tool") is a personal, internally-used application that publishes short-form video content — including content created for MediaMaxxing creator campaigns — to the operator's own TikTok and Instagram accounts. This policy explains what data the Tool touches and how it is handled.

Data the Tool accesses

To publish content, the Tool uses each platform's official API with access explicitly granted by the connected account through that platform's own authorization flow. This may include:

  • Basic account identifiers needed to publish to the correct account (e.g. a user ID and username).
  • An access token issued by the platform, used only to make publishing API calls.
  • The video files, captions, and metadata the operator submits for posting.

Data the Tool does not collect

  • The Tool does not collect data from any account other than the operator's own connected accounts.
  • It does not read followers, DMs, comments from other users, or any content the operator did not submit for posting.
  • It does not sell, share, or transfer any data to third parties.
  • It does not use data for advertising, profiling, or any purpose unrelated to publishing the operator's own content.

Storage

Access tokens and configuration needed to publish content are stored locally on the operator's own device, and are not transmitted anywhere except to the relevant platform's official API endpoints.

Revoking access

The operator can revoke the Tool's access at any time from the connected platform's own app-permissions settings (e.g. TikTok's or Instagram's "Apps and Websites" settings), which immediately invalidates any tokens the Tool holds.

Changes to this policy

This policy may be updated from time to time as the Tool's use changes. The date above reflects the most recent revision.
